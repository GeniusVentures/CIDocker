## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker build → static.rust-lang.org | rustup-init installer downloaded and executed during build |
| Docker build → github.com/adoptium/temurin25-binaries | JDK tarball downloaded and extracted into /usr/lib/jvm |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | rustup-init binary | mitigate | SHA256 pin verified via `sha256sum -c` before execution (the only pinned artifact — parity with the analog) |
| T-02-06 | Spoofing | rustup download URL | mitigate | HTTPS to `static.rust-lang.org/rustup/archive/1.28.2/...` + SHA256 pin |
| T-02-07 | Tampering | Temurin JDK tarball | accept | GitHub TLS + release provenance only; the analog does not SHA256-pin the JDK (parity — hardening is a deferred user decision) |
| T-02-08 | Elevation of privilege | `chmod -R a+w $RUSTUP_HOME $CARGO_HOME` | accept | Required for CI to install extra toolchains/components at run time; scoped to the rustup/cargo dirs only |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No npm/PyPI/crates packages — upstream tarballs only (Package Legitimacy Audit clean; slopcheck not applicable) |
</threat_model>
